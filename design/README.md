# 界面设计稿

QuickBar 的九块界面稿，用 Claude Design 的画布格式（`.dc.html`）画的。

画布分两页。

**快捷条**

| 画板 | 画的是 |
|---|---|
| `Main` | 常规态——⌥双击后弹在鼠标旁边 |
| `Filter` | 拼音筛选：输 `xz` 命中「下载」 |
| `Panel` | 在上传/保存窗里的形态，动作从「打开」变成「跳转到此」 |
| `MenuBar` | 菜单栏图标和它的菜单 |
| `Onboarding` | 首次启动的权限引导 |

**设置窗**（对应四个侧栏分页）

| 画板 | 画的是 |
|---|---|
| `Settings` | 条目——含悬停、改名中、已运行、找不到四种行状态 |
| `Trigger` | 触发方式和快捷键 |
| `Permissions` | 三项授权的状态 |
| `General` | 启动、文件面板尺寸、更新 |

每块都带一个 `dark` 开关，深浅色都能看。`canvas.json` 管排布和分页，外加五条便签，记着几个决定了实现方式的结论。

## 和实现的关系

这版稿子已经对着 v1.4.0 的实际界面改过一轮，画的就是现在的样子——包括后来才加的
重命名、拼音筛选、条目找不到时的标记，以及设置窗那四个分页。

但它终究是稿子不是规格：代码继续改的话这里不会自动跟着变。**以实际运行的软件为准**。

## 怎么改

`src/` 里是真正的授权输入：`_style.txt` 是九块共用的样式，`*.body.html` 是各自的内容。根目录的 `*.dc.html` 是把两者拼起来的产物——**别直接改它们**，改 `src/` 然后重新生成：

```bash
cd design && python3 src/build.py
```

生成完可以喂给 Claude Design 的画布工具重新发布，或者直接用浏览器打开单个 `.dc.html` 看效果。

## 示例内容说明

稿子里的文件夹名（`~/Work/素材库`、`秋季新品` 之类）都是编的示例，只为了让版式看起来真实，跟任何人的实际目录无关。
