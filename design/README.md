# 界面设计稿

QuickBar 动手写代码之前的六块界面草图，用 Claude Design 的画布格式（`.dc.html`）画的。

| 画板 | 画的是 |
|---|---|
| `Main` | 快捷条常规态——⌥双击后弹在鼠标旁边 |
| `Panel` | 快捷条在上传/保存窗里的形态，动作从「打开」变成「跳转到此」 |
| `Settings` | 设置窗 · 条目管理 |
| `Trigger` | 设置窗 · 触发方式、快捷键、权限 |
| `MenuBar` | 菜单栏图标和它的菜单 |
| `Onboarding` | 首次启动的权限引导 |

每块都带一个 `dark` 开关，深浅色都能看。`canvas.json` 管这六块在画布上的排布，外加三条便签，记着当时定下的几个关键结论。

## 已经和实现不一致的地方

这些是**动工前**的草图，不是现在的界面规格。后来在真机上撞出来的问题改变了几个决定：

- **设置窗侧边栏**改成了固定宽度自绘。稿子里画的是系统的 `NavigationSplitView`，但它的侧栏能拖到折叠，而恢复折叠要靠「显示」菜单——QuickBar 是 `LSUIElement` 后台程序，压根没有菜单栏，折叠了就再也回不来。
- **列表底部按钮**从三个图标简化成 macOS 标准的 `+` / `−` 一对，`+` 点开选文件夹还是应用。三个宽度不一的 SF Symbol 摆一起很难看齐。
- 后来加的功能稿子里没有：条目重命名、拼音筛选、条目找不到时的置灰标记。

要看实际界面，直接跑软件。

## 怎么改

`src/` 里是真正的授权输入：`_style.txt` 是六块共用的样式，`*.body.html` 是各自的内容。根目录的 `*.dc.html` 是把两者拼起来的产物——**别直接改它们**，改 `src/` 然后重新生成：

```bash
cd design && python3 src/build.py
```

生成完可以喂给 Claude Design 的画布工具重新发布，或者直接用浏览器打开单个 `.dc.html` 看效果。
