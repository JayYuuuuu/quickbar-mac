# QuickBar

macOS 上的快捷条。连按两下 ⌘ 唤出，跳转文件夹、启动应用；在上传或保存窗里按 ⌘G 直达 Finder 当前目录——Finder 里选中了哪个文件就落在那个文件上。面板和 Finder 新窗口的尺寸都替你记住。

开机自启、静默常驻，没有 Dock 图标，只在菜单栏留一个可关的入口。

## 功能

| | |
|---|---|
| **唤出** | 连按两下 ⌘，完全不碰鼠标事件。也可以选「⌥ + 双击任意位置」「双击桌面空白处」「裸双击」 |
| **跳转文件夹** | 复用当前 Finder 窗口，不新开——所以窗口尺寸不会被重置 |
| **启动应用** | 已在运行就切到前台，没运行才启动 |
| **⌘G 直达** | 在任何上传 / 保存窗里按 ⌘G，直接跳到 Finder 最前窗口所在的目录；那里选中了单个文件就直接落在这个文件上 |
| **记住面板尺寸** | 文件面板不再每次都是那个小方块 |
| **Finder 新窗口尺寸** | 新建的目录、网络卷上的目录，Finder 一律开成 960×492；替你改成惯用尺寸 |
| **静默更新** | 后台检查 GitHub Release，验签通过后换版本重启，全程无感 |
| **素材批次** | 接上「AI 电商内容助手」后，最近派的素材下载批次直接出现在快捷条上，下完还会通知 |
| **网页上点「在 Finder 打开」** | 「AI 电商内容助手」的页面上点一下，这台 Mac 的访达就跳到那个素材文件夹（`quickbar://`，只开访达） |
| **主图丢进 PS** | 在 Finder 里选中几个商品文件夹，旁边浮出一颗按钮，点一下每件的**首图**（3 比 4 和 1 比 1 各一张）都在 Photoshop 里打开（去水印那道工序） |
| **存回原位** | 改完在 PS 里按 ⌃⌘S：拼合、按这张图**自己的**原路径覆盖存回、关掉。不用再在存储对话框里翻回那个素材文件夹 |
| **最近素材批次** | 家目录里的 `~/最近素材批次/`，最近 12 批的替身，跟着服务器自动更新；拖进 Finder 侧栏就常驻 |

## 安装

从 [Releases](https://github.com/JayYuuuuu/quickbar-mac/releases) 下载 `QuickBar.zip`，解压后把 `QuickBar.app` 拖进「应用程序」，打开即可。

首次打开会引导你完成三项授权：

| 授权 | 没有它会怎样 |
|---|---|
| 辅助功能 | 判断不了当前是不是文件面板，也调不了面板尺寸 |
| 输入监控 | 收不到唤出快捷条的双击和 ⌘G |
| 自动化 · Finder | 读不到 Finder 当前文件夹，⌘G 会退回上次记住的路径 |

三项都是本地能力，QuickBar 不上传任何东西。出站请求只有两个：查 GitHub 有没有新版本；开了「素材批次」的话，按你填的地址去读一份批次目录清单。

> 应用是自签名的，不是 Apple Developer ID。首次打开如果被 Gatekeeper 拦下，在「系统设置 → 隐私与安全性」里点一下「仍要打开」。

## 素材批次（可选，团队内部用）

「AI 电商内容助手」派的素材下载单，落盘的形状是 `<采集根>/<品牌>/<20260820-1305_补素材>/`
—— **每派一单就是一个新的时间戳目录**。所以这批目录手工加书签没有意义，今天加的明天就不指向任何东西。
QuickBar 从服务端把它们取回来，当成会自己更新的条目：

- 上传窗里唤出快捷条 → 输品牌名 → 回车，面板直接落到那个批次目录，不用一层层点。
- 批次下完了弹一条通知，点一下就在 Finder 里打开它。
- 菜单栏常驻一个「打开最新批次」，不弹快捷条也能进去。

默认就是开的，什么都不用填：服务器地址和那串只读口令都在构建时内置。
口令在服务端只能读 `/api/listing-source/history`（批次落在哪个目录、下完没有），
派单、重下、回写一律够不着 —— 快捷条上按错一下不该能动到线上数据。
不需要就在「设置 → 素材批次」里关掉。

> 口令不在这个仓库里：`build.sh` 从 `QUICKBAR_MATERIAL_KEY` 或 `~/.quickbar-material-key`
> 读出来写进 `Info.plist`。自己 clone 下来编的包没有口令，设置页会露出「密码」那一栏让你手填。

## 网页上那个「在 Finder 打开」

「AI 电商内容助手」的**品牌素材变动**页里，每件商品都写着素材下到了哪个文件夹。
以前只能复制路径、切到访达按 ⌘⇧G 粘贴——因为网页**开不了本地文件夹**：
https 页面里的 `file://` 链接浏览器一律拦掉，而那台服务器在 NAS 上，够不着你面前这台 Mac 的访达。

装了 QuickBar 就有人接这一下了：页面上那个按钮是条 `quickbar://reveal?path=…` 链接，
系统交给 QuickBar，它复用当前 Finder 窗口跳过去（跟快捷条跳转是同一条路，窗口尺寸不会跳）。
第一次点浏览器会问「是否允许在 QuickBar 中打开」，勾上「始终允许」就不再问。

- **只开访达**：这条协议只认 `reveal` 一个动作，不执行任何命令、不读文件内容、不回传任何东西。
- **路径有闸门**：只放行 `/Volumes`（素材盘都在这儿）和你的家目录，`..` 会先折平再判，绕不过去。
- **不会「点了没反应」**：文件夹被挪走或删了，就退到还找得到的上一层，并弹一条通知说清是怎么回事。
- 没装 QuickBar 的机器上，页面旁边永远还留着「复制路径」那个按钮。

## 素材下载完之后那两下（团队内部用）

下载下来的一批素材长这样：`<批次>/<商品>_<ID>/{主图, 主图1比1, SKU图, 详情图, 视频}/`，
一批六十来个商品。第一道人工工序是**去掉主图上的品牌水印**（PS 里改完存回原文件）。
真正花时间的不是修图，是前面那三跳——翻到批次、翻到商品文件夹、进 `主图/`、一张张拖进 PS，
每件商品重来一遍。两个入口把这三跳合成一下：

- **选中就浮出来的那颗按钮**：在 Finder 里选中几个商品文件夹（或整个批次目录），
  旁边（Finder 窗口右下角）浮出 `主图丢进 PS · 3 张`，点一下就全开了。手不用离开刚选文件的地方。
  只在**真的解析出了主图**时才出现——点了不会白点。不想要它浮出来：设置 → 素材批次里关掉。
- **菜单栏「主图丢进 PS」**：同一件事的另一个入口（浮窗关掉了、或者想对当前窗口整批来一下）。
- **网页上单件的「主图丢进 PS」**：品牌素材变动页的抽屉里，只想改这一件时用它。
- **每件开两张首图**：`主图/`（3 比 4）和 `主图1比1/`（1 比 1）各一张——这是两套**不同的**图，
  不是同一张的裁剪版，两边都要去水印。同一件商品的两张在 PS 里挨着，好认。
- **只开首图**，因为水印一般只烧在第一张上。全开的代价是实打实的：一批 63 件光 `主图/`
  就五百多张标签页，人还得自己认哪张要改。超过 30 张会先问一声。
- 要改这两条：`MainImages` 里 `SUB_DIRS`（开哪几个子目录）/ `FIRST_ONLY`（首图还是全开）各一行。

### 改完之后：⌃⌘S 存回原位

丢进 PS 只是前半程。动过生成式填充 / 内容识别之后图层不止一个，⌘S 就变成「存储为」，
对话框落在上次去过的目录，每张都要重新翻回 `/Volumes/…/<批次>/<商品>_<ID>/主图/`；
一次开了几十张之后，人根本认不出手上这张是哪件商品的。

**「存哪个文件夹」不该由人回答**——PS 自己就记着每个文档是从哪个文件打开的。
所以这里不是「帮你把对话框跳到正确目录」，是把对话框整个拿掉：

- 在 Photoshop 里按 **⌃⌘S**（这个键只在 PS 在最前时被拦截，别处照旧）：
  当前这张拼合 → 按它自己的原路径覆盖写回 → 关掉 → 下一张自动露出来。
- PS 里还有没存回的图时，窗口下缘中间浮出 `存回原位 · 还剩 N 张`，点一下同一件事。
- 菜单栏 **「全部存回原位」**：一次把打开的全存回去（会先问一声）。
- 菜单栏 **「PS 当前这张在访达里」**：偶尔要去翻同一件商品的别的图时用。
- **只认 jpg 和 png**。覆盖写回意味着原图没了，别的扩展名一律不碰，会明说跳过了几张。
- JPEG 存 **Photoshop 第 9 档**，不是最高的 12。实测（1440×1920 的真素材）：原图 733 KB、
  q9 684 KB、q12 1.48 MB —— 12 档把体积翻一倍，多出来的精度大半花在保留原图自己的压缩痕迹上，
  而图传上去还会被平台再压一次。9 档的量化精度比原图略细，重编码那一道损耗有余量兜着。
  （别往 6 以下降：PS 在 7 档以下切到 4:2:0，色度减半，布料花色和文字会发虚。）
- 用的是 **PS 的「存储为」那条路**（`save … as JPEG`），跟你手动「文件 → 存储为」逐项一致：
  品质 9、嵌入颜色配置文件、格式选项「基线已优化」。**不是**「导出为 / 存储为 Web 所用格式」——
  那是另一套引擎（画质刻度 0–100，还会把 EXIF/XMP/ICC 剥光）。
- ⚠️ **原图会被改完的这版替掉，没有撤销**。整件事就是「去掉水印再存回原文件」，
  但这一条得看得见。不想要：设置 → 素材批次里关掉（快捷键和浮窗一起关）。

第一次按会弹一次系统授权（「QuickBar 想要控制 Photoshop」），允许一次就够了。

**`~/最近素材批次/`**：Finder 侧栏只收真实存在的文件夹，所以这就做成一个真目录——
里面是最近 12 批的替身（符号链接），服务器那份清单一变就重建。把它拖进侧栏一次，
以后点开就是最新那几批。手工加书签跟不上，是因为每派一单就换一个新的时间戳目录。
里面只有替身，删掉不影响真素材；不想要就在「设置 → 素材批次」里关掉，目录会自己收走。

## 它是怎么做到的

几条不那么显然、但决定实现方式的事实（都在 macOS 26 上实测过）：

**文件面板的判定**。不管宿主应用是否沙盒（沙盒应用的面板其实由 `com.apple.appkit.xpc.openAndSavePanelService` 绘制），面板都会以 `AXIdentifier = open-panel / save-panel` 出现在「当前聚焦应用的 `AXFocusedWindow`」上。三次属性读取就能判定，实测 0.5ms 量级。

反过来两件事千万别做：别去数 `openAndSavePanelService` 进程——它有多个实例常驻，面板关了进程也不退；别在事件 tap 回调里遍历 AX 子树——一次几千个节点会被系统直接判超时，把整个 tap 禁掉（表现是快捷键毫无征兆全部失灵）。

**面板尺寸**。普通窗口型面板可以用 AX 直接改（要按 size → position → size 的顺序，中间那次改位置是为了避开 macOS 把窗口夹回屏幕的逻辑）。Chrome 这类把面板做成 `AXSheet` 的，AX 改不动——`isAttributeSettable` 会返回 true，然后静默失败。这种只能写宿主应用的 `NSNavPanelExpandedSizeForOpenMode` 偏好，下次打开生效。

**「前往文件夹」吃文件路径**。⌘⇧G 的输入框里给一个完整的**文件**路径，面板会落到它的父目录并且把这个文件选中，再回车就是打开它。前提是用 AX 直接写 `AXValue`——用合成按键逐字符敲会被自动补全接管，回车被吃掉，什么也不会发生。

**Finder 窗口尺寸**。不是全局设置，是**按文件夹逐个记**的，记在**父目录的 `.DS_Store`** 里（`bwsp` 记录，一段 binary plist，含 `WindowBounds`），而且**关窗那一刻才写盘**。没有记录的文件夹一律开成 960×492，跟「上一个窗口多大」无关——一个 1520×1020 的窗口开着时新开一个没记录的文件夹，仍然是 960×492，只是位置错开。macOS 没有「默认窗口尺寸」这个偏好可以改。于是两种情况每次都是小窗口：每次新建的目录（素材批次那种时间戳目录）天生没有记录；`DSDontWriteNetworkStores = 1` 时 Finder 根本不往网络卷写 `.DS_Store`（在 SMB 共享上把窗口拉大再关掉，`.DS_Store` 的 mtime 纹丝不动），尺寸只活在 Finder 进程内存里，Finder 一重启全丢。所以只能在窗口出现的那一刻自己改，而且只动尺寸恰好等于 960×492 的——别的尺寸是那个文件夹自己记着的，覆盖了就是帮倒忙。

**跟 Photoshop 说话不能占着主线程**。Apple Event 是同步等待的，PS 只要压着任何模态框（存储进度、生成式填充、缺字体提示）就一直不回复——实测从终端问它「打开了几个文档」，40 秒都没回来。所以这一发跑在一条**自带 run loop 的专用线程**上：run loop 是关键，在没有 run loop 的 `DispatchQueue` 上 `NSAppleScript` 会一声不响地返回空。为了不把这一条赌进去，每次动作的第一发永远是只读探测，真撞上「空且无错」就把后面所有调用切回主线程——只读的重来一次没有代价，写盘的不能赌。另外 20 秒没回话就主动说一句「PS 多半正压着一个对话框」，绝不「按了没反应」。

**签名与自动更新**。macOS 的 TCC 授权是按签名主体记的。如果用 ad-hoc 签名，每次构建 cdhash 都变，静默更新完权限就掉了——所以必须用固定证书签，"静默"才成立。更新包下载后用**当前运行版本自己的 designated requirement** 去校验，签名主体或 bundle id 对不上直接丢弃。

## 界面设计稿

界面稿在 [`design/`](design/)（Claude Design 画布，深浅色都有）。「快捷条」那份已经落地到 v1.14.0 —— 药丸、快捷条本体、菜单栏图标、引导页、App 图标都照着改过；「设置窗」那份还没。稿子终究不是规格，**以实际运行的软件为准**。

## 从源码构建

需要 macOS 13+ 和 Swift 6 工具链（Xcode 或 Command Line Tools）。

```bash
git clone https://github.com/JayYuuuuu/quickbar-mac.git
cd quickbar-mac
./build.sh                 # 出 dist/QuickBar.app
./build.sh 1.0.0           # 指定版本，同时出 dist/QuickBar.zip
```

默认找名为 `LocalShot Internal Code Signing` 的证书；用 `QUICKBAR_SIGN_ID` 换成你自己的：

```bash
QUICKBAR_SIGN_ID="Developer ID Application: Your Name (TEAMID)" ./build.sh 1.0.0
```

找不到证书会退回 ad-hoc 签名，能跑，但每次重新构建都要重新授权，只适合本地临时试。

## 已知限制

- Electron / Qt / JetBrains 自绘的文件选择器不是 `NSOpenPanel`，⌘G 对它们无效。浏览器上传是标准面板，没问题。
- 保存窗的 ⌘G 只跳目录，不跟选中的文件——文件路径会被填进名字栏，等于默认覆盖同名文件。
- sheet 型面板（Chrome）的尺寸记忆是**下次打开生效**，不是当场变。
- 沙盒应用的面板尺寸偏好写在它自己的容器里，QuickBar 改不到，只能靠 AX 当场调整。
- 非沙盒应用，上不了 App Store。
